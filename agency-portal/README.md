# 代理店ポータル（マイページ + 管理画面 + スプレッドシート）

代理店からの紹介を LINE のメッセージで受けるのをやめて、**代理店ごとの専用URL（マイページ）**に入力してもらう仕組みです。
入力・修正された内容はすべて **Google スプレッドシート**にそのまま溜まり、弊社側はスプレッドシートか管理画面のどちらからでもリアルタイムに編集できます。

```
代理店（スマホ）              弊社
┌──────────────┐      ┌────────────────────┐
│ マイページ            │ ←──→ │ スプレッドシート（正データ）│
│ ?a=<トークン>         │      │  ・紹介／代理店マスタ        │
│  紹介の登録・修正      │      │  ・お知らせ・LP／設定       │
│  進捗の確認           │      │  ・ダッシュボード（自動集計）  │
│  専用LPの取得         │      │  ・変更履歴（追記専用）      │
└──────────────┘      └────────────────────┘
        ↑ URLをLINEにピン留め          ↑ 管理画面 ?admin=<トークン>
```

## なぜスプレッドシートを「アプリのデータベース」にしたのか

「アプリが落ちてもスプシに情報が残っていてほしい」「代理店が修正したらスプシにも反映してほしい」という要件に対して、
別のデータベースを立てて同期させると、必ず“ズレ”と“同期が止まる”問題が出ます。
スプレッドシート自体をデータベースにすれば、**同期という工程がそもそも存在しない**ので、この要件は原理的に満たされます。
加えて、弊社側の「リアルタイムに編集したい」も、シートを直接触るだけで実現します（サーバーもデプロイも不要）。

## どのアカウントでデプロイするか（重要）

**結論：弊社の独自ドメインのアカウントでそのままデプロイして大丈夫です。@gmail.com の代理店も開けます。**

Apps Script のウェブアプリは、デプロイ時に「アクセスできるユーザー」を選びます。

| 選択肢 | 誰が開けるか |
| --- | --- |
| 自分のみ | 自分だけ |
| ◯◯.co.jp 内の全員 | 同じドメインのアカウントだけ |
| **全員** | **Googleアカウントの有無を問わず、URLを知っている人全員** |

「全員」を選べば、代理店が @gmail.com でも、そもそもGoogleにログインしていなくても開けます。
このとき **「次のユーザーとして実行：自分」** にしておくので、スプレッドシートへの書き込みは弊社の権限で行われます。
代理店にスプレッドシートを共有する必要はありません。

### もし「全員」が選べない場合

Google Workspace の管理者が外部共有を制限していると、「全員」が出てこないことがあります。その場合は次の順に検討してください。

**A. 管理コンソールで外部共有を許可する（おすすめ）**
管理コンソール → アプリ → Google Workspace → ドライブとドキュメント → 共有設定 で、外部共有をオンにします。
組織全体を変えたくない場合は、この用途のアカウントだけを対象にした組織部門（OU）を作り、そこだけ許可する方法もあります。

**B. @gmail.com でデプロイし、書き込み先は弊社のスプレッドシートにする**
「gmailでデプロイすると出力先もgmailのスプシになるのでは」というご懸念は、**なりません**。スクリプトと保存先は切り離せます。

1. 弊社ドメインのスプレッドシートを、その @gmail.com アカウントに **編集者** として共有する
2. @gmail.com 側で **単独の（スプレッドシートに紐づかない）** Apps Script プロジェクトを作り、同じコードを貼る
3. エディタで次を一度だけ実行する（IDはスプレッドシートURLの `/d/` と `/edit` の間の文字列）

   ```javascript
   setTargetSpreadsheetId('1AbCdEfGhIjKlMnOpQrStUvWxYz...');
   ```

4. 続けて `setupSpreadsheet()` を実行し、あとは通常どおりデプロイする

これで、代理店が入力したデータは**最初から弊社のスプレッドシートに直接書き込まれます**。転記も同期も発生しません。
（この構成ではスプレッドシートのメニュー［代理店ポータル］は出ないので、セットアップ系の関数はエディタから実行してください。）

**C. 関数だけで転記する場合（非推奨）**
`IMPORTRANGE` で別スプレッドシートの内容を取り込むことは可能ですが、**読み取り専用のコピー**になります。
弊社側でステータスを直せませんし、元シートが壊れれば取り込み先も壊れます。上記A・Bのどちらも取れない場合の最終手段です。

## セットアップ（15分ほど）

### 1. スプレッドシートと Apps Script を用意する

1. Google ドライブで新しいスプレッドシートを作成し、名前を「代理店ポータル」などにする
2. **拡張機能 → Apps Script** を開く
3. `src/` の中身を、次の対応でエディタに作成・貼り付ける

   | このリポジトリのファイル | Apps Script 上のファイル名 | 種類 |
   | --- | --- | --- |
   | `src/Config.gs` | `Config.gs` | スクリプト |
   | `src/Store.gs` | `Store.gs` | スクリプト |
   | `src/Setup.gs` | `Setup.gs` | スクリプト |
   | `src/Code.gs` | `Code.gs`（最初からある `コード.gs` を置き換え） | スクリプト |
   | `src/Copy.gs` | `Copy.gs` | スクリプト |
   | `src/StyleV2.html` | `StyleV2` | HTML |
   | `src/AgencyV2.html` | `AgencyV2` | HTML |
   | `src/AdminV2.html` | `AdminV2` | HTML |
   | `src/Message.html` | `Message` | HTML |
   | `src/Style.html` | `Style` | HTML（旧デザイン。不要なら省略可） |
   | `src/Agency.html` | `Agency` | HTML（旧デザイン。不要なら省略可） |
   | `src/Admin.html` | `Admin` | HTML（旧デザイン。不要なら省略可） |

   > HTML ファイルは「ファイル ＋ → HTML」で追加します。ファイル名に `.html` は付けません（`Agency` と入力）。
   > `clasp` を使う場合は `.clasp.json.example` を `.clasp.json` にコピーして `scriptId` を入れ、`npx @google/clasp push` で一括反映できます。

4. エディタを保存して、スプレッドシートを**開き直す**（メニューが出ます）

### 2. シートを自動生成する

スプレッドシートのメニュー **［代理店ポータル］→［初期セットアップ／再点検］** を実行します。
初回は権限の承認を求められるので許可してください。次の6つのシートが作られます。

| シート | 役割 |
| --- | --- |
| `ダッシュボード` | 稼働中が何件あるかなどの自動集計（全部数式なので常に最新） |
| `紹介` | 代理店が入力した紹介データ本体 |
| `代理店マスタ` | 代理店・専用LP・マイページURL |
| `お知らせ・LP` | マイページに載せるお知らせ／最新LP |
| `説明会日程` | 週2回の代理店向け説明会など、選ばせたい日時 |
| `文面テンプレート` | 代理店の「紹介文をつくる」で使う文面 |
| `設定` | 会社名・選択肢・通知先など。**ここを直すとアプリの表示が即変わります** |
| `変更履歴` | 登録・更新のたびに1行ずつ積まれる追記専用の台帳 |

### 3. ウェブアプリとしてデプロイする

1. Apps Script エディタで **デプロイ → 新しいデプロイ → 種類：ウェブアプリ**
2. **次のユーザーとして実行：自分** / **アクセスできるユーザー：全員**
3. 発行された URL（`https://script.google.com/macros/s/.../exec`）をコピー
4. スプレッドシートの `設定` シート、**「ウェブアプリURL」の値**に貼り付ける

これで `代理店マスタ` の「マイページURL」列と、`設定` の「管理画面URL」が自動で組み上がります。

### 4. 代理店を登録する

メニュー **［代理店ポータル］→［代理店を追加］**、または管理画面の［代理店］タブから追加します。
`代理店マスタ` に直接行を書いてもかまいませんが、その場合は **アクセストークン列を空にしない**でください（推測されにくい24文字を入れる）。

登録すると「マイページURL」が生成されるので、それを代理店に渡し、**LINEのトークにピン留め**してもらいます。

### 5. 通知メール（任意）

`設定` シートの「通知先メールアドレス」を入れると、新しい紹介が登録されるたびにメールが届きます。
不要なら「新規登録メール通知」を `OFF` にしてください。

## 画面の説明

### 代理店マイページ（スマホ前提）— `?a=<アクセストークン>`

下部のタブで4つの画面を行き来します。

**ホーム**
- **目標** … 「まずは10社のご紹介を目指しましょう。達成まで、あと4社です。」達成すると次の10社が出ます（件数は `設定` シートで変更）
- 合計 / 進行中 / 稼働中 / 失注 の4つの数字
- **⚠️ 情報が足りない件数** … 会社名・氏名・メール・電話・詳細のうち未入力があるものを数えています
- **御社専用 AI活用研修 説明LP** … コピー / そのまま開く
- **代理店候補の方にお渡しするLP** … 候補ごとに違うURLを一覧で表示。取り違え防止のため、氏名と会社名を添えてコピーできます
- 弊社からのお知らせ・最新資料

**ご紹介** … お客様 / 代理店候補で切り替え、ステータスで絞り込み。カードをタップして修正。

**紹介文** … LINE・メールでそのまま送れる文面をつくります（後述）。

**説明会** … 公開中の日程、残席、案内文のコピー、個別調整用の予約URL。

### 管理画面（社内）— `?admin=<管理者トークン>`

ダッシュボード / 紹介一覧 / 代理店 / お知らせ・LP / 説明会日程 / 文面テンプレート の6タブ。
弊社メモ・次回アクション日は代理店に**送信していません**（画面で隠しているのではなく、データを渡していません）。

### デザインを元に戻したいとき

初期デザイン（v1）も残してあります。`設定` シートの「UIバージョン」を `v1` にするか、URLの末尾に `&ui=v1` を付けてください。
現行デザインは `v2` です。

## 代理店候補の取り分（マージン）

代理店候補のご紹介には2通りの進め方があり、マイページで選べます。

| 管理方式 | 内容 | 取り分 |
| --- | --- | --- |
| **トスアップ** | 弊社がすべて対応する | 紹介元の代理店に固定％（既定3%。`設定` シートで変更） |
| **自己管理** | 代理店が自分で候補を管理する | 代理店の基本マージン率を、候補と自由に分け合う（例：基本20% → 候補15% / 自分5%） |

- 基本マージン率は **代理店ごと** に持ちます（`代理店マスタ` の「基本マージン率(%)」。20%の会社も10%の会社もある前提）
- 自己管理のとき、**候補＋自分の合計が基本マージン率を超える入力はサーバー側で弾きます**。画面には常に「合計 20% / 基本 20%（残り 0%）」と残りが出ます
- 候補にお渡しするリファラー付きLPは、弊社が管理画面で発行します。代理店側は表示とコピーのみ（書き換えはできません）

## 紹介文をつくる

代理店がLINE・メールでそのまま送れる文面を用意する画面です。

1. 「お客様 / 代理店候補」「LINE / メール」を選ぶ
2. 相手の名前・自分の名前・案内するURLを入れる
3. **過去に自分が送ったメッセージを貼る**（任意）
4. 「文面をつくる」→ 訴求軸の違う3案が出て、それぞれコピー / そのまま送信

文面のもとになるテンプレートは `文面テンプレート` シートで弊社が編集できます。
`{相手}` `{自分}` `{会社}` `{LP}` `{日時}` が自動で差し込まれます。

**文体の寄せ方は2段階あります。**

| モード | 条件 | 動き |
| --- | --- | --- |
| ルールベース（既定） | 常に利用可 | あいさつ・一人称・相手の呼び方（さん/様）・絵文字の量・改行の細かさ・テンションを、貼られた文面から写します |
| AIリライト | `設定` の「文面AIリライト」を `ON` ＋ Claude APIキー | Claude が文体を読み取って本文ごと書き換えます |

AIリライトを使う場合は [console.anthropic.com](https://console.anthropic.com) でAPIキーを発行し、`設定` シートに貼ってください。
モデルは `Claudeモデル` で変更できます（既定 `claude-opus-5`。安く抑えるなら `claude-sonnet-5` / `claude-haiku-4-5`）。
1回の生成でおよそ2,000入力＋1,500出力トークン程度です。APIが落ちてもルールベースに自動で切り替わるので、画面が止まることはありません。

## 説明会の予約

「まず説明会に出てから考える」という方が多いので、2つの導線を用意しています。

1. **決まった日程から選ぶ** … `説明会日程` シート（または管理画面）に、週2回の代理店向け説明会などを登録します。
   代理店は説明会タブから日程を選び、案内文をコピーして相手に送り、「案内済みとして記録」を押します。
   定員を入れておくと残席が出ます（申込数は紹介シートから自動集計）。
2. **日程が合わないとき** … `設定` シートの「個別日程調整URL」に **TimeRex 等の予約ページURL** を入れておくと、
   説明会タブにコピー用のボタンが出ます。予約者名・メールアドレスは、ご紹介先ご本人に入力していただく前提です。

紹介1件ごとに「説明会ステータス（未案内／案内済／日程調整中／予約確定／参加済／不参加）」と日程が記録され、
管理画面とスプレッドシートの両方から確認できます。

## データ設計

### `紹介` シート

| 列 | 内容 |
| --- | --- |
| 紹介ID | `R-20260826-A1B2C3` 形式で自動採番 |
| 登録日時 / 更新日時 | 自動 |
| 代理店ID / 代理店名 | どの代理店からの紹介か |
| 種別 | `顧客紹介`（AIバード／AI活用研修に興味）または `代理店紹介`（代理店候補） |
| 会社名 / 氏名 / メールアドレス / 電話番号 / 詳しい情報 | 代理店に入力してもらう項目 |
| 興味商材 | 顧客紹介のときだけ |
| ステータス | 新規 / アプローチ中 / 商談中 / 稼働中 / 保留 / 失注 / 取り下げ |
| 失注理由 | ニーズなし / 代理店化を辞退 / 音信不通 / 予算が合わない / 競合他社に決定 / 時期尚早 / その他 |
| 管理方式 | 代理店紹介のみ。トスアップ / 自己管理 |
| 紹介元マージン(%) / 候補マージン(%) | 代理店紹介のみ |
| 候補用LP_URL | 弊社が発行し、代理店が候補にお渡しするLP |
| 説明会ステータス / 希望日程ID / 説明会日時 | 説明会の進捗 |
| 次回アクション日 / 弊社メモ | 社内用（代理店には送信していません） |
| 最終更新者 | 代理店名 または「弊社」 |
| 情報の充足 | **数式列。** `◯ 完了` / `△ 未入力: メール 電話` のように自動表示 |

> 「情報の充足」列、`代理店マスタ` の「マイページURL」列、`説明会日程` の「申込数」列は ARRAYFORMULA です。**スクリプトはこれらの列に書き込みません**（そのため数式列は必ず各シートの末尾に置いています）。
> 手でシートを編集しても自動で再計算されます。数式を消してしまった場合は［初期セットアップ／再点検］で復活します。
> 列を追加したあとに［初期セットアップ／再点検］を実行すると、既にデータがある場合は正しい位置に列を挿入してから見出しを揃えます（値がズレません）。

### `変更履歴` シート

新規登録・更新・ステータス変更のたびに1行追記されます。`スナップショット` 列にその時点の全項目が JSON で入るので、
**`紹介` シートの行を誤って消しても、履歴から内容を復元できます。**

### 選択肢を増やしたいとき

`設定` シートの「ステータス選択肢」「失注理由選択肢」「興味商材選択肢」をカンマ区切りで書き換えるだけで、
マイページと管理画面のプルダウンが即座に変わります（再デプロイ不要）。
シート側のプルダウンにも反映したい場合は［初期セットアップ／再点検］を実行してください。

## 権限とセキュリティ

- 代理店の URL は**推測されにくい24文字のトークン**で守られています。ログイン不要にしているのは、LINEから1タップで開けることを優先したためです。
- 代理店が触れるのは**自分の紹介だけ**です。他社の紹介IDを指定してもサーバー側で弾きます。
- **弊社メモ・次回アクション日は代理店の画面に送信していません**（画面で隠しているのではなく、そもそもデータを渡していません）。
- ステータスを代理店に編集させたくない場合は、`設定` の「代理店によるステータス編集」を `不可` にしてください。
- URLが外部に漏れたら、管理画面の代理店編集画面から **［URLを再発行］** で即座に無効化できます。
- 管理画面URLは社内限定です。共有してしまった場合は［代理店ポータル］→［管理者トークンを再発行］。
- 代理店候補にお渡しするLPのURLは、代理店側からは**書き換えられません**（弊社が発行した値のみ表示・コピーできます）。
- Claude APIキーは `設定` シートに置かれ、スプレッドシートの閲覧権限を持つ人だけが見られます。代理店の画面には送信していません。

## 開発・検証

Apps Script API をモックして、サーバー側ロジックを Node で実行できます。

```bash
node test/run-tests.cjs      # 99件のテスト（登録・更新・権限・履歴・通知・マージン・説明会・文面生成など）
node test/build-preview.cjs  # test/preview/*.html に画面のプレビューを生成（ブラウザで開けます）
```

`test/gas-mock.cjs` は `SpreadsheetApp` / `Utilities` / `LockService` / `MailApp` の最小実装です。
数式は評価されないため、数式列の中身そのものは検証していません（数式が正しくセットされることだけ確認しています）。

## 今後の拡張メモ

- 代理店が30社から増えても、`代理店マスタ` に行を足すだけで対応できます。
- 紹介件数が数千件を超えて表示が重くなってきたら、`Store.gs` の `readAll_` を期間で絞る実装に変えるのが最初の一手です。
- LINEのリッチメニューから開かせる場合も、マイページURLをそのまま設定すれば動きます。
- 説明会の予約を「代理店が押したらカレンダーに入る」ところまで自動化したい場合は、Google Calendar API を足すのが次の一手です。現状は日程の記録までで、実際の招待は弊社側の運用に委ねています。
- 見出しは Google Fonts の Noto Serif JP を読み込みますが、読み込めない環境ではOS標準の明朝（ヒラギノ明朝／游明朝）にフォールバックします。
