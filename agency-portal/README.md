# 代理店ポータル（マイページ + 管理画面 + スプレッドシート）

代理店からの紹介を LINE のメッセージで受けるのをやめて、**代理店ごとの専用URL（マイページ）**に入力してもらう仕組みです。
入力・修正された内容はすべて **Google スプレッドシート**にそのまま溜まり、弊社側はスプレッドシートか管理画面のどちらからでもリアルタイムに編集できます。

```
代理店（スマホ）              弊社
┌──────────────┐      ┌────────────────────┐
│ マイページ            │ ←──→ │ スプレッドシート（正データ）│
│ ?a=<トークン>         │      │  ・紹介／代理店マスタ        │
│  紹介の登録・修正      │      │  ・お知らせ・LP／設定       │
│  進捗の確認           │      │  ・ダッシュボード（自動集計）  │
│  専用LPの取得         │      │  ・変更履歴（追記専用）      │
└──────────────┘      └────────────────────┘
        ↑ URLをLINEにピン留め          ↑ 管理画面 ?admin=<トークン>
```

## なぜスプレッドシートを「アプリのデータベース」にしたのか

「アプリが落ちてもスプシに情報が残っていてほしい」「代理店が修正したらスプシにも反映してほしい」という要件に対して、
別のデータベースを立てて同期させると、必ず“ズレ”と“同期が止まる”問題が出ます。
スプレッドシート自体をデータベースにすれば、**同期という工程がそもそも存在しない**ので、この要件は原理的に満たされます。
加えて、弊社側の「リアルタイムに編集したい」も、シートを直接触るだけで実現します（サーバーもデプロイも不要）。

## セットアップ（15分ほど）

### 1. スプレッドシートと Apps Script を用意する

1. Google ドライブで新しいスプレッドシートを作成し、名前を「代理店ポータル」などにする
2. **拡張機能 → Apps Script** を開く
3. `src/` の中身を、次の対応でエディタに作成・貼り付ける

   | このリポジトリのファイル | Apps Script 上のファイル名 | 種類 |
   | --- | --- | --- |
   | `src/Config.gs` | `Config.gs` | スクリプト |
   | `src/Store.gs` | `Store.gs` | スクリプト |
   | `src/Setup.gs` | `Setup.gs` | スクリプト |
   | `src/Code.gs` | `Code.gs`（最初からある `コード.gs` を置き換え） | スクリプト |
   | `src/Style.html` | `Style` | HTML |
   | `src/Agency.html` | `Agency` | HTML |
   | `src/Admin.html` | `Admin` | HTML |
   | `src/Message.html` | `Message` | HTML |

   > HTML ファイルは「ファイル ＋ → HTML」で追加します。ファイル名に `.html` は付けません（`Agency` と入力）。
   > `clasp` を使う場合は `.clasp.json.example` を `.clasp.json` にコピーして `scriptId` を入れ、`npx @google/clasp push` で一括反映できます。

4. エディタを保存して、スプレッドシートを**開き直す**（メニューが出ます）

### 2. シートを自動生成する

スプレッドシートのメニュー **［代理店ポータル］→［初期セットアップ／再点検］** を実行します。
初回は権限の承認を求められるので許可してください。次の6つのシートが作られます。

| シート | 役割 |
| --- | --- |
| `ダッシュボード` | 稼働中が何件あるかなどの自動集計（全部数式なので常に最新） |
| `紹介` | 代理店が入力した紹介データ本体 |
| `代理店マスタ` | 代理店・専用LP・マイページURL |
| `お知らせ・LP` | マイページに載せるお知らせ／最新LP |
| `設定` | 会社名・選択肢・通知先など。**ここを直すとアプリの表示が即変わります** |
| `変更履歴` | 登録・更新のたびに1行ずつ積まれる追記専用の台帳 |

### 3. ウェブアプリとしてデプロイする

1. Apps Script エディタで **デプロイ → 新しいデプロイ → 種類：ウェブアプリ**
2. **次のユーザーとして実行：自分** / **アクセスできるユーザー：全員**
3. 発行された URL（`https://script.google.com/macros/s/.../exec`）をコピー
4. スプレッドシートの `設定` シート、**「ウェブアプリURL」の値**に貼り付ける

これで `代理店マスタ` の「マイページURL」列と、`設定` の「管理画面URL」が自動で組み上がります。

### 4. 代理店を登録する

メニュー **［代理店ポータル］→［代理店を追加］**、または管理画面の［代理店］タブから追加します。
`代理店マスタ` に直接行を書いてもかまいませんが、その場合は **アクセストークン列を空にしない**でください（推測されにくい24文字を入れる）。

登録すると「マイページURL」が生成されるので、それを代理店に渡し、**LINEのトークにピン留め**してもらいます。

### 5. 通知メール（任意）

`設定` シートの「通知先メールアドレス」を入れると、新しい紹介が登録されるたびにメールが届きます。
不要なら「新規登録メール通知」を `OFF` にしてください。

## 画面の説明

### 代理店マイページ（スマホ前提）— `?a=<アクセストークン>`

- **上部の4つの数字** … 合計 / 進行中 / 稼働中 / 失注
- **⚠️ 情報が足りない件数** … 会社名・氏名・メール・電話・詳細のうち未入力があるものを数えています。
  「どこまで弊社に伝えきっているか」が一目で分かり、タップすると該当分だけ絞り込めます。
- **御社専用 AI活用研修 説明LP** … 弊社が代理店ごとに用意したリファラー付きLPを表示。コピー／そのまま開くボタン付き。
- **弊社からのお知らせ・最新資料** … LPが差し替わったときなどはここに出します（全代理店向け／特定の代理店だけ、も選べます）。
- **ご紹介一覧** … 「お客様 / 代理店候補」で切り替え、ステータスで絞り込み。カードをタップすると内容を修正できます。
- **＋ 紹介を登録** … 最初に「お客様のご紹介」か「代理店候補のご紹介」かを選ぶ形式。氏名だけ必須で、あとから追記できます。

### 管理画面（社内）— `?admin=<管理者トークン>`

- **ダッシュボード** … 全体サマリと代理店別の内訳。稼働中の多い順に並び、稼働中セルは緑で目立ちます。行をクリックするとその代理店の紹介一覧へ。
- **紹介一覧** … 代理店／種別／ステータス／フリーワードで絞り込み。行をクリックしてステータス・失注理由・次回アクション日・**弊社メモ**（代理店には見えません）を編集。
- **代理店** … 追加・編集、マイページURLのコピー、専用LPのURL設定、停止、URLの再発行。
- **お知らせ・LP** … マイページに出す内容の追加・編集・掲載/下書きの切り替え。

## データ設計

### `紹介` シート

| 列 | 内容 |
| --- | --- |
| A 紹介ID | `R-20260826-A1B2C3` 形式で自動採番 |
| B 登録日時 / C 更新日時 | 自動 |
| D 代理店ID / E 代理店名 | どの代理店からの紹介か |
| F 種別 | `顧客紹介`（AIバード／AI活用研修に興味）または `代理店紹介`（代理店候補） |
| G 会社名 / H 氏名 / I メールアドレス / J 電話番号 / K 詳しい情報 | 代理店に入力してもらう項目 |
| L 興味商材 | 顧客紹介のときだけ（AIバード / AI活用研修 / 両方 / 未定） |
| M ステータス | 新規 / アプローチ中 / 商談中 / 稼働中 / 保留 / 失注 / 取り下げ |
| N 失注理由 | ニーズなし / 代理店化を辞退 / 音信不通 / 予算が合わない / 競合他社に決定 / 時期尚早 / その他 |
| O 次回アクション日 / P 弊社メモ | 社内用（代理店には送信すらしていません） |
| Q 最終更新者 | 代理店名 または「弊社」 |
| R 情報の充足 | **数式列。** `◯ 完了` / `△ 未入力: メール 電話` のように自動表示 |

> R列と、`代理店マスタ` のL列（マイページURL）は ARRAYFORMULA です。**スクリプトはこの2列に書き込みません**。
> 手でシートを編集しても自動で再計算されます。数式を消してしまった場合は［初期セットアップ／再点検］で復活します。

### `変更履歴` シート

新規登録・更新・ステータス変更のたびに1行追記されます。`スナップショット` 列にその時点の全項目が JSON で入るので、
**`紹介` シートの行を誤って消しても、履歴から内容を復元できます。**

### 選択肢を増やしたいとき

`設定` シートの「ステータス選択肢」「失注理由選択肢」「興味商材選択肢」をカンマ区切りで書き換えるだけで、
マイページと管理画面のプルダウンが即座に変わります（再デプロイ不要）。
シート側のプルダウンにも反映したい場合は［初期セットアップ／再点検］を実行してください。

## 権限とセキュリティ

- 代理店の URL は**推測されにくい24文字のトークン**で守られています。ログイン不要にしているのは、LINEから1タップで開けることを優先したためです。
- 代理店が触れるのは**自分の紹介だけ**です。他社の紹介IDを指定してもサーバー側で弾きます。
- **弊社メモ・次回アクション日は代理店の画面に送信していません**（画面で隠しているのではなく、そもそもデータを渡していません）。
- ステータスを代理店に編集させたくない場合は、`設定` の「代理店によるステータス編集」を `不可` にしてください。
- URLが外部に漏れたら、管理画面の代理店編集画面から **［URLを再発行］** で即座に無効化できます。
- 管理画面URLは社内限定です。共有してしまった場合は［代理店ポータル］→［管理者トークンを再発行］。

## 開発・検証

Apps Script API をモックして、サーバー側ロジックを Node で実行できます。

```bash
node test/run-tests.cjs      # 58件のテスト（登録・更新・権限・履歴・通知など）
node test/build-preview.cjs  # test/preview/*.html に画面のプレビューを生成（ブラウザで開けます）
```

`test/gas-mock.cjs` は `SpreadsheetApp` / `Utilities` / `LockService` / `MailApp` の最小実装です。
数式は評価されないため、数式列の中身そのものは検証していません（数式が正しくセットされることだけ確認しています）。

## 今後の拡張メモ

- 代理店が30社から増えても、`代理店マスタ` に行を足すだけで対応できます。
- 紹介件数が数千件を超えて表示が重くなってきたら、`Store.gs` の `readAll_` を期間で絞る実装に変えるのが最初の一手です。
- LINEのリッチメニューから開かせる場合も、マイページURLをそのまま設定すれば動きます。
