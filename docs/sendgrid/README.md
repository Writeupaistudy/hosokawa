# SendGrid Design Editor 共通テンプレート 構築手順書

株式会社ライトアップ メルマガ共通テンプレート（補助金 / セミナー / AIサービス 兼用）

---

## 0. はじめに — ブラウザ操作について

**このセッションからは、SendGrid の画面を直接操作できません。** 理由は次の2点です。

1. 実行環境が隔離されたクラウドコンテナで、SendGrid にログイン済みのブラウザセッションを引き継いでいません（認証情報もありません）。
2. コンテナの通信は制限されており、`https://mc.sendgrid.com/` への接続がプロキシに拒否されます（実測 `403`）。

そのため代わりに、**このドキュメントの手順どおりにクリックすれば同じものが完成する**レベルまで、ブロックの種類・順番・設定値をすべて確定させました。あわせて次の2ファイルを用意しています。

| ファイル | 用途 |
| --- | --- |
| `preview.html` | 完成イメージ。ブラウザで開いて答え合わせに使う（**Code Editor に貼る用ではありません**） |
| `assets/banner-placeholder.png` | メインバナーの仮画像（1200×600px）。SendGrid の画像ライブラリにアップして使う |

> `preview.html` でロゴを表示したい場合は、ライトアップの赤ロゴを `assets/logo-writeup.png` として保存してください。

---

## 1. 事前準備（先に済ませておくと手が止まりません）

### 1-1. 画像を2点アップロードする

SendGrid 左メニュー **Marketing → Design Library**（または画像モジュールの編集画面）から、画像ライブラリに次の2点をアップロードします。

| 画像 | 推奨サイズ | 備考 |
| --- | --- | --- |
| ライトアップ 赤ロゴ | 横 360px 以上（表示は 180px） | 背景透過 PNG 推奨。高解像度ディスプレイ対策で表示幅の2倍を用意 |
| `assets/banner-placeholder.png` | 1200×600px（表示は 600px） | 毎回差し替える仮画像 |

### 1-2. Unsubscribe Group を1つ作っておく

**Marketing → Unsubscribe Groups → Create Unsubscribe Group**
名前は「メールマガジン」などでOK。これがないと配信停止リンクが実際には機能しません（Single Send 送信時にこのグループを選びます）。

### 1-3. テンプレートを新規作成する

**Marketing → Design Library → Create a Design → Blank Template → Design Editor**

名前は `【共通】ライトアップ メルマガ ver1` のように、共通テンプレートだと一目で分かるものにしてください。

---

## 2. 全体設定（Settings / Design タブ）

ブロックを置く前に、まず全体設定を済ませます。左サイドバーの **Settings**（バージョンにより「Design」「General Styles」表記）を開き、次の値を入れます。

| 項目 | 設定値 |
| --- | --- |
| Content Width（本文の横幅） | **600 px** |
| Background Color（メール全体の背景） | `#f3f6f9` |
| Content / Container Background（本文の背景） | `#ffffff` |
| Font Family | **Arial**（日本語は端末の游ゴシック・ヒラギノ等に自動フォールバックします） |
| Link Color | `#1769aa` |

### カラーパレット（この6色だけを使います）

| 用途 | カラーコード | 使いどころ |
| --- | --- | --- |
| メインカラー（青） | `#1769aa` | 見出しの飾り、マイクロコピー、リンク |
| 濃紺（見出し・フッター背景） | `#17324d` | 大見出し、フッター |
| 本文グレー | `#3f5368` | 本文 |
| 補足グレー | `#718096` | 注釈・小さい文字 |
| 淡い青（共感ブロック背景） | `#edf6fc` | 「こんなお悩み〜」の背景 |
| **CTAオレンジ** | `#f58220` | **CTAボタンのみ**。他では使わないので目立ちます |

> 青ベースの中でオレンジは補色に近く、最もクリックが集まる配色です。中小企業経営者向けの「派手すぎず信頼感」も、オレンジを CTA だけに限定することで両立します。

## 3. ブロック構成（上から順に9行）

Design Editor は「**Row（行）を置く → その中に Module（部品）をドラッグする**」という2段構えです。以下、**行ごと**に「行の設定」と「中に入れるモジュール」を書きます。

すべて **1カラム（Single Column）** の Row を使います。

### 全体像

```
行1  ロゴ ＋ 区切り線
行2  メインバナー画像            ┐
行3  短い訴求文（2〜3行）        │ ファーストビュー
行4  マイクロコピー ＋ CTAボタン①┘
行5  こんなお悩みはありませんか？（淡い青背景）
行6  今回のご案内
行7  詳細情報（対象・内容・日時・費用）
行8  マイクロコピー ＋ CTAボタン②
行9  フッター（会社情報・配信停止）
```

```
対　象　【詳細情報を入力】

費　用　【詳細情報を入力】
```

ラベル部分（`対　象` など）だけを選択して **Bold ON / Color `#17324d`** にします。

> **ご指示どおり「概要」という独立ブロック（青い見出しバー）は作っていません。**
> **項目名は全角スペースで2文字幅に揃えています**（`対　象` `内　容` `日　時` `費　用`）。等幅に見えるので、表組みを使わなくても整って見えます。
> 用途によって項目を入れ替えてください。補助金なら「対象／対象経費／申請期限」、セミナーなら「対象／内容／日時／費用」、AIサービスなら「対象／できること／料金」。
>
> **表組み（罫線つき）にしたい場合の代案**：2カラム Row（左28% / 右72%）を項目数ぶん並べ、左カラムの背景を `#f6f9fb` にします。見た目は添付HTMLに近づきますが、項目を1つ増やすたびに Row を追加する手間がかかるため、毎号使い回す共通テンプレートとしては上記の Text モジュール1つ方式を推奨します。

```

```

1行目を選択 → リンクボタン → `https://www.writeup.jp/` を設定 → **文字色 `#ffffff` ＋ 下線** にします（濃紺背景ではデフォルトの青リンクが読めないため、ここは必ず白に変更してください）。

**モジュール③：配信停止リンク** ← 重要

方法は2つあります。**方法A を推奨**します。

#### 方法A（推奨）：Text モジュール＋リンク種別「Unsubscribe」

1. Text モジュールを置き、`配信停止はこちら` と入力
2. その文字を選択して **リンクボタン** をクリック
3. リンク設定ダイアログの **Link Type / Link To** のプルダウンで **`Unsubscribe`** を選ぶ
   （同じプルダウンに `Unsubscribe Preferences`＝配信設定変更ページ、`View in Browser` もあります）
4. 文字色 `#ffffff` ＋ **下線 ON**、Font Size `11` px、Padding 上 `14`

これで SendGrid が送信時に正しい配信停止URLを自動で埋め込みます。プルダウンが見当たらないバージョンでは、URL欄に置換タグ **`[Unsubscribe]`** を直接入力しても同じ結果になります。

#### 方法B：Unsubscribe モジュールをドラッグ

モジュール一覧の **Unsubscribe** をフッター行にドラッグします。確実に機能しますが、文言やデザインの自由度が方法Aより低いので、フッターの見た目を揃えたい場合は方法Aが扱いやすいです。

> **注意**：配信停止リンクは、**Single Send 送信時に Unsubscribe Group を選択して初めて機能します**（1-2 で作成したもの）。Design Editor のプレビュー画面ではダミーのままなので、「リンクが効かない」と誤解しないでください。実挙動の確認はテスト配信で行います（下記5参照）。

## 4. 保存と複製（毎号の使い方）

1. 右上 **Save** → 左上のテンプレート名が `【共通】ライトアップ メルマガ ver1` になっていることを確認
2. **Design Library** に戻る
3. 作ったテンプレートの右端 **⋯（三点メニュー）→ Duplicate**
4. 複製されたものの名前を `20260901_ものづくり補助金のご案内` のように変更
5. **複製した方だけを編集**する（マスターは絶対に上書きしない）

> これが「テンプレートを複製して繰り返し使える」の運用ルールです。マスターを直接編集してしまう事故が一番多いので、名前に `【共通】` を付けて見分けられるようにしています。

### 毎号、差し替える箇所チェックリスト

| # | 場所 | 仮テキスト |
| --- | --- | --- |
| 1 | 行2 バナー画像 | `【メインバナーを変更】`（Alt Text も変更） |
| 2 | 行3 訴求文 | `【短い訴求文を入力】`（2箇所） |
| 3 | 行4 マイクロコピー | `【マイクロコピーを入力】` |
| 4 | 行4 CTAボタン文言 | `【CTA文言を入力】`（10文字以内） |
| 5 | 行4 CTAボタンURL | `【CTAリンクを設定】` |
| 6 | 行5 悩み3行 | `【読者の悩みを入力】`（3箇所） |
| 7 | 行6 本文 | `【今回の案内を入力】` |
| 8 | 行7 詳細情報 | `【詳細情報を入力】`（4箇所） |
| 9 | 行8 マイクロコピー・CTA | 行4と同じ（**URLの変え忘れに注意**） |
| 10 | バナー画像のリンク先 | 行2の Image モジュールの Link |

> **一番多いミスは「行8のCTAのURLだけ変え忘れる」**です。保存前に必ず両方のボタンをクリックしてURLを確認してください。

### プリヘッダーについて

添付HTMLの冒頭にあった非表示のプリヘッダー用 `<div>` は、テンプレート内に作る必要はありません。**Single Send の作成画面に「Preheader」入力欄がある**ので、そこに毎回40〜70文字で入れてください（受信箱で件名の横に出る文章です）。

## 5. 完成後のチェック

| 確認項目 | 確認方法 |
| --- | --- |
| 各テキストをクリックして編集できる | 各 Text モジュールをクリック → カーソルが入り、直接打ち替えられる |
| 画像をドラッグ＆ドロップで差し替えられる | Image モジュールをクリック → **Replace Image** → 画像ライブラリから選ぶ／PCからドラッグして直接アップ |
| CTAのURLをコードなしで変更できる | Button モジュールをクリック → 右パネルの **Link / URL** 欄を書き換えるだけ |
| スマホ表示で崩れていない | エディタ右上の**スマホアイコン**でモバイルプレビュー。さらに **Send Test** で自分宛に送り、実機のGmailアプリで確認（プレビューと実機はレンダリングが違うため、実機確認まで必須） |
| 配信停止リンクが機能する | **Single Send を作成 → Unsubscribe Group を選択 → 自分宛にテスト送信 → 実際にリンクをクリック**して停止画面が出るか確認 |
| テンプレートを複製して繰り返し使える | Design Library → ⋯ → **Duplicate** が出れば OK |

### 追加で見ておくと安心なポイント

- **画像OFFで読めるか**：Gmail の画像非表示状態でも、バナー以外のテキストだけで内容が伝わるか（だからバナー画像内に重要情報を閉じ込めないでください）
- **ダークモード**：Gmail アプリのダークモードで、濃紺フッターの白文字が潰れていないか
- **リンク切れ**：テスト送信メールから全リンク（ロゴ・バナー・CTA×2・会社URL・配信停止）をクリックして遷移先を確認
